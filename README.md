# Wedstrijdkansen

Voorspellingen voor Scorito: Eredivisie, KKD, Premier League, Championship, La Liga, Serie A, Bundesliga, 2. Bundesliga, Ligue 1, Liga Portugal, Pro League en Nations League.

- `src/` — pagina-onderdelen en build-scripts
- `index.html` — gegenereerd met `python3 src/build_page.py`
